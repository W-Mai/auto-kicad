# Changelog

## 0.1.0

MCP server for KiCad schematic and PCB inspection, approved editing, ERC/DRC checks, selected schematic-to-PCB synchronization and manufacturing exports.

Release archives cover macOS ARM64/x86_64, Linux ARM64/x86_64 and Windows x86_64, with shell and PowerShell installers, checksums, corresponding source and dependency notices. Native KiCad acceptance covers macOS ARM64 with KiCad 10.0.7. Additional platform builds have no runtime acceptance guarantee.
