# Private schematic audit

`SchematicAudit::prepare` observes a closed schematic hierarchy through a private native project, configuration and library snapshot. Server-owned `SchematicAuditPolicy` supplies canonical source and approved resource locations. Preparation binds source bytes and explicit absent files, resolves effective symbol and footprint tables, copies used resources with exact digests, and redirects effective library rows to the private copies. Footprint lookup retains missing-nickname, disabled, missing-file and present states without placement fallback mappings.

The private configuration selects English and initializes against an owned empty schematic. Native netlist export and complete ERC run twice under fixed executable/environment inputs; the results and settled configuration must remain stable. Initialization may create the exact initially absent private `.kicad_prl`, whose contents are bound before repeated validation. Source/project/library/configuration contents, catalog resolution, hierarchy locks and private file sets are rechecked. Missing files appearing, changed library contents, added private files and changed configuration sets invalidate the observation. Configuration rewrites preserve unknown raw JSON numeric values and reject duplicate keys.

## Native acceptance

KiCad 10.0.7 exported the same netlists and complete language-matched ERC reports from the source baselines and private snapshots. ECC83 retained 15 components, 26 units, 13 nets and zero ERC diagnostics. Multichannel retained 114 components, 169 units, 80 nets, five sheet instances, 4 errors and 32 warnings. Its unresolved legacy footprint nicknames remain unresolved. Both cases verify source/project/table/configuration changes, used source symbol changes, private symbol/footprint changes and added configuration/project files. ECC83 additionally verifies used source footprint changes; multichannel uses installed footprint files, which the runner leaves untouched.

A conflicting-variable case verifies that a project text variable selects its local symbol library despite conflicting external and stored configuration values. Removing a used footprint file preserves all 4 native footprint-link warnings and the original netlist. Source and private ERC reports use the same English setting for exact comparison. The initial harness failure from an assumed project-local footprint and the initial mixed-language comparison failure are retained separately.

All original examples, retained baseline copies and test input snapshots remain unchanged after validation and restored drift controls. Each audit removes its private directory on drop. No editor was launched. Full workspace checks passed: capability matrix, formatting, warning-denied Clippy on all targets, and 503 tests with zero failures and 15 environment-dependent tests ignored. The existing production fixed-circuit CLI/MCP regression passed separately.

## Scope and reproduction

This is a read-only backend observation, exposed through the `observe` mode of [bounded schematic MCP](schematic-general-mcp.md). [Exported logical component-pin membership](schematic-pins.md) is checked during preparation. `observe_pin_connectivity` adds a separate [private native witness](schematic-connectivity.md) for supported omitted power/virtual pins while retaining original ERC evidence. A separate [typed candidate compiler](schematic-edit-candidates.md) edits supported source objects without granting publication approval. Publication/recovery and schematic-to-PCB synchronization are not provided by this audit API. Configuration must already contain initialized common settings and global library tables. Absolute or variable child-file paths, child symlink aliases, variable footprint assignments, external drawing sheets and explicitly enabled simulation-model checks are rejected. Native runtime dependencies and all possible external schematic resources are not fully bound; this observation alone cannot authorize general schematic writes.

`check-schematic-audit` accepts an owned schematic, owned configuration root, baseline XML, language-matched baseline ERC JSON and a new output directory. Both input roots require `.auto-kicad-audit-owned` containing `schematic-audit-acceptance` followed by a newline. The example checks complete native equality, performs reversible drift controls only in owned locations, and verifies private-directory cleanup. [schematic-audit.json](schematic-audit.json) records the 4 native cases, quality gates and retained artifact hashes.
